# cv-lab3

# Сегментация дорожных знаков и трекинг

Ноутбук декодирует аннотации дорожных знаков в маски сегментации, обучает DeepLabV3-ResNet50 и оценивает модель на валидационной выборке. Для оценки рассчитываются IoU, Precision, Recall и L2.

Дополнительно реализован пайплайн обработки видео: сегментационная маска преобразуется в детекции, после чего объекты связываются между кадрами с помощью IoU-трекера или CentroidTracker.

## Результаты на validation

- Macro IoU: **0.682**
- Macro Precision: 0.891
- Macro Recall: 0.744
- Средняя L2-ошибка: 0.049

## Данные

Ожидаются изображения и VIA-аннотации в `sign_dataset/train/` и `sign_dataset/val/`. Для обработки собственных фотографий и видео предусмотрены папки `my_photos/` и `videos/`.

## Запуск

Откройте `lab3.ipynb`, настройте пути к данным и выполните ячейки последовательно. Для трекинга ID Switches нужны GT-треки в формате MOTChallenge.
